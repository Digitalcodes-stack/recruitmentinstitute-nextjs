SECTION 5 — KEY ARCHITECTURAL DECISIONS CAPTURED TODAY
================================================================================

  5A. LOCAL-FIRST AI STRATEGY (FINALISED)
      The removal of claude_provider.py, gemini_provider.py, and
      openai_provider.py marks the final commitment to running 100% local AI:
        - Embeddings   : sentence-transformers/all-MiniLM-L6-v2 (via FAISS)
        - NLP Pipeline : spaCy en_core_web_sm + NLTK
        - LLM          : HuggingFace transformers (local_llm_provider)
        - RAG           : FAISS vector store + custom retrieval_service
      BENEFIT: Zero API cost, works offline, no data leaves the server.
      TRADEOFF: Requires heavier Docker image (4 GB RAM on Cloud Run).

  5B. DEPLOYMENT ARCHITECTURE (Google Cloud Run — Mumbai)
      Both services are independently containerised and scaled:
        - FastAPI (AI backend): 2 CPU / 4 GB RAM — needed for ML models
        - Next.js (frontend):   1 CPU / 1 GB RAM — stateless, fast to scale
      Secrets managed via Google Secret Manager (not env file in image).
      Alembic migrations run automatically at FastAPI startup (CMD).

  5C. STUDY PLAN AS FIRST-CLASS FEATURE
      The study-plan page expansion (+449 lines) elevates it from a simple
      text display to a structured, data-driven view. This is the primary
      post-assessment deliverable a student receives alongside the PDF report.
