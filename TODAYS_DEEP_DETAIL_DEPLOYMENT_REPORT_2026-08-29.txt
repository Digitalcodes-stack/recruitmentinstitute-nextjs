TASK 1: AI VOICE ASSISTANT ("TALK TO PRIYA") WIDGET REPAIR & UI ENHANCEMENT
--------------------------------------------------------------------------------
• Problem:
  - The voice talk assistant was not appearing on the bottom right of the live site.
  - Root Cause: In src/app/layout.tsx, the script tag pointed to 
    /desk/admin/talk-widget.js. Because Next.js serves static assets from public/, 
    and the widget files were located in AI-Desk/static/, production returned HTTP 404.
  - The original button was positioned at bottom: 22px, colliding with the chat button.
  - The modal action button was labeled "Start" instead of "Call".

• Solution Implemented:
  1. Asset Synchronization:
     - Copied entire talk-widget suite (talk-widget.js, HTML, and avatar PNG frames 
       including mouth-closed, mouth-mid, mouth-open) into:
       - public/desk/admin/
       - public/desk/
     - Verified HTTP 200 OK on live URL: 
       https://recruitmentinstitute.in/desk/admin/talk-widget.js
  2. "Start" to "Call" Transformation:
     - Modal prompt updated to: "Enter your name, then click Call and allow microphone access."
     - Action button converted to: [📞 Call] with embedded SVG phone icon.
     - Live call state converted to: [⏹ End Call].
     - Floating button (FAB) updated to a sleek call/phone icon.
  3. Responsive Positioning:
     - Positioned at bottom: 90px; right: 22px; floating directly above WhatsApp.

TASK 5: COURSES PAGE (/courses) DYNAMIC REVIEWS COUNTER
--------------------------------------------------------------------------------
• Problem:
  - The "Programs at a Glance" panel on /courses showed "0 Reviews".

• Solution Implemented:

    1. Hero panel "Programs at a Glance" (under the green accent)
    2. Stats strip "Course Reviews" card
