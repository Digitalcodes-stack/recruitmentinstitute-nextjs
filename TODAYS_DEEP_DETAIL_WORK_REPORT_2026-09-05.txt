TASK 3: STUDENT AUTHENTICATION, LOGOUT & REDIRECT SANITIZATION
--------------------------------------------------------------------------------
• Problem Identified:
  - On signout, the browser was redirecting to `https://0.0.0.0:3000/student-login`, 
    which resulted in an unreachable ERR_CONNECTION_REFUSED error.
  - When clicking links after student login, Next.js client-side router cache 
    occasionally bounced users back to `/student-login`.

• Solution Implemented:
  1. Host Sanitization:
     - Updated auth logout handlers and server redirects to strip bind-all IP 
       addresses (`0.0.0.0`) and resolve to the current `window.location.origin` 
       or canonical domain `https://recruitmentinstitute.in`.
  2. Router Cache Fix:
     - Replaced `router.push('/profile')` upon successful login with a clean 
       `window.location.href = '/profile'`, ensuring fresh cookies and hydration 
       of student sessions.
  3. Verified complete student login -> dashboard -> logout lifecycle without bounces.
