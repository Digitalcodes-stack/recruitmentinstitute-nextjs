[C] ATTENDANCE-GATED AI ASSESSMENT ENGINE
----------------------------------------------------------------------------------------------------
* Business Rule: When a trainer finalizes attendance, only students marked "Present" receive the AI
  assessment for the topics covered in that session. Absent students must not receive it.
* Implementation:
  1. Database Schema (`prisma/schema.prisma`):
     - `Session`: Added `syllabusModuleId`, `moduleNameSnapshot`, `topicsJson`.
     - `SessionAssessment`: Stores link between session, course, module name, and FastAPI assessment ID.
     - `SessionAssessmentStudent`: Pivot table mapping `sessionAssessmentId` to eligible `studentId`.
  2. Release Service (`lib/services/assessmentReleaseService.ts`):
     - `releaseAssessmentForPresentStudents(sessionId)`:
       a) Identifies students marked Present in `attendance`.
       b) Reads session's `topicsJson` and `moduleNameSnapshot`.
       c) Triggers FastAPI backend `/admin/assessments` to generate topic-specific questions.
       d) Inserts `SessionAssessmentStudent` eligibility records for Present students only.
       e) Duplicate protection: Guarantees a session cannot release duplicate assessments.
  3. Trainer Attendance Hook (`src/app/api/trainer/attendance/route.ts` & `TrainerAttendanceClient.tsx`):
     - When trainer clicks "Save Attendance Register", session status is updated to `COMPLETED`.
     - `releaseAssessmentForPresentStudents` runs automatically.
     - Trainer UI displays a confirmation banner:
       "✅ Assessment Released — [Module Name] | X Present, Y Absent | X Got Assessment".
       Displays notice: "🔒 Y absent student(s) will NOT receive this assessment."

----------------------------------------------------------------------------------------------------
1. Auto Meet Link:
   - When creating a session (single, series, or auto-batch), if meet link is empty, a standard Google
     Meet code is generated and saved automatically.

     is hidden and replaced with a `✓ Session Completed` badge.

   - Join route (`/api/sessions/[id]/join`) rejects joins to concluded sessions.
